FERRAMENTAS / 018

O que faz um profissional não é o menu de ferramentas.

Este catálogo reúne sistemas, protocolos e recursos que aparecem no cotidiano de investigação e defesa. Comandos curtos e seguros, contexto de uso e limites para estudos autorizados.

18 ENTRADAS
01

Linux

SISTEMAS

Sistema de arquivos, permissões, processos e serviços.

uname -a whoami ls -lah ps aux | head
Comece entendendo o sistema que você administra.
02

Kali Linux

SISTEMAS

Distribuição voltada a testes de segurança e investigação autorizada.

cat /etc/os-release apt list --installed | head
Distribuição não substitui método nem autorização.
03

Wireshark

REDE

Captura e interpretação de pacotes com filtros de exibição.

dns tcp.port == 443 http.request
Filtros de exibição são exemplos para tráfego sob sua responsabilidade.
04

Nmap

REDE

Inventário de ativos e serviços em ambientes próprios.

nmap -sV 127.0.0.1
O comando verifica seu próprio host local.
05

tcpdump

REDE

Captura de pacotes em linha de comando.

sudo tcpdump -i lo -c 10
O exemplo limita a captura à interface de loopback.
06

Suricata

DETECÇÃO

IDS/IPS que examina tráfego e gera eventos.

suricata --version suricata -T -c /etc/suricata/suricata.yaml
Teste configuração antes de operar no tráfego.
07

Wazuh

DETECÇÃO

Ferramenta aberta para análise de eventos, inventário e monitoramento de endpoints.

sudo systemctl status wazuh-agent
Exemplo apenas se o agente estiver instalado.
08

Zeek

DETECÇÃO

Framework para gerar logs estruturados a partir de tráfego de rede.

zeek --version
Os registros devem ser interpretados no contexto.
09

SQLite

DADOS

Banco leve para organizar eventos e consultas locais.

sqlite3 --version
Separar coleta, retenção e acesso facilita auditoria.
10

Cloudflare Workers

INFRAESTRUTURA

Execução de código na borda para validação e ingestão de eventos.

npx wrangler --version
Não coloque segredos de produção no navegador.
11

Git

DESENVOLVIMENTO

Histórico de mudanças, comparação de versões e recuperação.

git status git log --oneline -5
Backup e revisão antes de cada publicação.
12

OpenSSL

CRIPTOGRAFIA

Ferramentas para observar certificados e gerar valores aleatórios.

openssl version openssl rand -hex 16
Nunca publique chaves privadas.
13

journalctl

SISTEMA

Leitura de logs de serviços no Linux.

journalctl -p err -n 20
Analise eventos, não apenas contagens.
14

ss

REDE

Visibilidade local de conexões e portas abertas.

ss -tulpen
Ajuda a revisar a superfície exposta no host.
15

curl

WEB

Inspeção de respostas HTTP e cabeçalhos.

curl -I https://example.org
Teste URLs e ativos para os quais tem permissão.
16

Python

AUTOMAÇÃO

Processamento de logs, relatórios e testes automatizados.

python3 --version
Automatize tarefas verificáveis e registre resultados.
17

MITRE ATT&CK

CONHECIMENTO

Base estruturada de táticas e técnicas observadas.

https://attack.mitre.org/
Mapa de comportamento, não lista mágica de bloqueios.
18

NIST CSF

GOVERNANÇA

Framework de funções para gerenciar riscos de cibersegurança.

https://www.nist.gov/cyberframework
Governar, identificar, proteger, detectar, responder e recuperar.
